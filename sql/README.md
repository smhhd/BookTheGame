# Phase 3 SQL

فایل‌های اصلی Schema در ریشه Repository باقی مانده‌اند. پس از اجرای
`create_db.sql`، `indexes.sql` و Seed، Migrationهای این پوشه را به ترتیب اجرا کنید.

`001_add_payment_reports.sql` تنها شکاف Schema با نیاز فاز سوم را برطرف می‌کند:
امکان گزارش مستقیم یک پرداخت. این Migration هیچ جدول یا داده‌ای را حذف نمی‌کند.

`002_phase3_completeness.sql` به‌صورت افزایشی تاریخ تولد اختیاری، موجودی کیف
پول و پاسخ متنی پشتیبان را اضافه می‌کند. Refund همچنان در جدول `refunds`
ثبت می‌شود و همان تراکنش، موجودی کیف پول را نیز افزایش می‌دهد.
